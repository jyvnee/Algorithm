# 택배 상자 꺼내기

## 사용 알고리즘

- 수학
- 구현
- 홀짝성을 이용한 방향 판별

## 풀이 기록

### v1

#### 풀이 아이디어

상자를 2차원 배열에 직접 쌓지 않고, 꺼내려는 상자와 가장 위층의 상자가 같은 열에 놓이는지를 계산한다.

상자 번호 `x`가 놓인 층과 해당 층에서 몇 번째로 놓였는지는 다음과 같다.

```text
층 번호 = ceil(x / w)
층 내 순번 = x % w (나머지가 0이면 w)
```

따라서 전체 상자의 최상층 정보는 `n`으로, 꺼내려는 상자의 층 정보는 `num`으로 구할 수 있다.

상자를 놓는 방향은 층마다 반대가 된다.

- 두 층 번호의 홀짝이 같으면 진행 방향도 같다.
  - 두 상자가 같은 열에 있으려면 층 내 순번이 같아야 한다.
  - 최상층에는 `topBoxCount`번째 상자까지만 존재하므로, 목표 상자의 층 내 순번이 `topBoxCount` 이하라면 목표 상자와 같은 열의 최상층에도 상자가 있다.
- 두 층 번호의 홀짝이 다르면 진행 방향이 반대다.
  - 목표 상자의 층 내 순번이 `myBoxCount`라면, 반대 방향에서 같은 열에 놓이는 순번은 `w - myBoxCount + 1`이다.
  - 이 순번이 `topBoxCount` 이하인지 확인한 식이 `topBoxCount + myBoxCount > w`이다.

목표 상자의 층부터 최상층까지 같은 열이 모두 채워져 있다면 꺼낼 상자 수는 다음과 같다.

```text
topFloor - myBoxFloor + 1
```

최상층의 같은 열이 비어 있다면 그 바로 아래층까지만 상자가 있으므로 다음과 같다.

```text
topFloor - myBoxFloor
```

#### 시간복잡도

```text
O(1)
```

층과 층 내 순번을 산술 연산으로 계산하고, 최상층의 상자 존재 여부를 조건문으로 한 번 판별한다. `n`이나 `w`의 크기와 관계없이 연산 횟수가 일정하다.

#### 공간복잡도

```text
O(1)
```

상자 배치를 저장하는 배열을 만들지 않고 몇 개의 정수 변수만 사용한다.

#### 개선 가능한 부분

- `Math.ceil((double) x / w)` 대신 `(x - 1) / w + 1`을 사용하면 형 변환 없이 정수 연산만으로 층 번호를 계산할 수 있다.
- `myBoxCount`는 상자의 개수가 아니라 층 안에서의 순번을 의미하므로, `positionInFloor`와 같은 이름을 사용하면 의도가 더 분명해진다.
- 최상층에 같은 열의 상자가 있는지를 `boolean` 변수로 분리하면 두 분기에서 반복되는 반환 코드를 하나로 합칠 수 있다.
- 현재 풀이는 이미 시간복잡도와 공간복잡도가 모두 `O(1)`이므로 점근적인 복잡도를 더 개선할 수는 없다.
