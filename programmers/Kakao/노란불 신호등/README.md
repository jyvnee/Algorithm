**☑️ 시간복잡도 / 공간복잡도**

신호 개수를 `N`, 모든 주기의 최소공배수를 `L`이라고 하자

모든 시간마다 모든 신호를 확인하므로,
```
시간복잡도: O(L × N)
공간복잡도: O(N)
```

**☑️ 최적화 방안**

- 모든 시간을 검사할 필요 없음
    
    어떤 신호 하나라도 노란불이 아니라면 정답이 될 수 없으므로, 노란불이 켜져 있는 시간의 비율이 가장 낮은 신호를 기준으로 잡기
