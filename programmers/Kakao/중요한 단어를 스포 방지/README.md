**☑️ 시간복잡도 / 공간복잡도**

메시지 길이를 N, 스포 구간 개수를 R, 전체 단어 수를 W, 서로 다른 단어의 개수를 U라고 하자

```
시간복잡도: O(N + R + U) = O(N)
공간복잡도: O(N + U) = O(N)
```

**☑️ 최적화 방안**

- 메시지의 각 문자를 스포 여부 배열에 표시하지 않고, 현재 단어 구간과 스포 구간이 겹치는지만 투 포인터로 확인할 수 있음

    스포 구간이 서로 겹치지 않고, 시작 인덱스 기준으로 정렬되기 때문
