# 모의고사

## 알고리즘 분류

- 완전탐색
- 시뮬레이션
- 배열

## 풀이 기록

### v1

#### 문제 정의

세 수포자는 각자 정해진 반복 패턴에 따라 답을 작성한다. 주어진 정답 배열과 각 수포자의 답을 비교하여 가장 많은 문제를 맞힌 사람의 번호를 오름차순으로 반환한다.

최고 점수가 같은 사람이 여러 명이라면 해당하는 사람을 모두 반환해야 한다.

#### 풀이 아이디어

각 수포자의 답안은 일정한 길이의 패턴이 반복된다.

```text
1번: 1, 2, 3, 4, 5
2번: 2, 1, 2, 3, 2, 4, 2, 5
3번: 3, 3, 1, 1, 2, 2, 4, 4, 5, 5
```

문제 번호 `i`에서 각 수포자가 고른 답은 패턴 배열의 `i % 패턴 길이` 위치에서 구할 수 있다. 따라서 `answers`를 한 번 순회하면서 세 패턴의 답을 실제 정답과 비교하고, 일치할 때 해당 수포자의 점수를 증가시킨다.

채점이 끝나면 세 점수 중 최댓값을 구한다. 최댓값과 같은 점수를 얻은 수포자를 1번부터 3번까지 차례로 결과에 담으면 별도의 정렬 없이 오름차순 결과를 만들 수 있다.

#### 알고리즘 풀이

1. 세 수포자의 반복 답안 패턴을 각각 배열로 저장한다.
2. 세 수포자의 정답 개수를 저장할 `correctCount` 배열을 생성한다.
3. `answers`를 처음부터 끝까지 순회한다.
   - 현재 문제 번호를 각 패턴의 길이로 나눈 나머지를 이용해 수포자의 답을 구한다.
   - 실제 정답과 일치하면 해당 수포자의 정답 개수를 증가시킨다.
4. `correctCount`의 세 값 중 최댓값을 구한다.
5. 최고 점수를 받은 수포자를 확인하여 그 수를 센다.
6. 최고 득점자 수만큼 결과 배열을 생성한다.
7. 수포자를 1번부터 3번까지 다시 확인하며 최고 득점자의 번호를 결과 배열에 저장한다.
8. 결과 배열을 반환한다.

#### 시간복잡도

정답의 개수를 `N`이라고 할 때 시간복잡도는 `O(N)`이다.

- 모든 정답을 한 번 순회하며 세 수포자의 답과 비교한다: `O(3N)`
- 세 명의 점수에서 최댓값과 최고 득점자를 찾는다: `O(3)`

```text
O(3N) + O(3)
→ O(N)
```

수포자의 수와 각 답안 패턴의 길이는 고정되어 있으므로 상수로 취급한다.

#### 공간복잡도

`O(1)`

- 세 개의 답안 패턴 배열, 점수 배열, 최고 득점 여부 배열을 사용한다.
- 반환 배열의 길이도 최대 3이다.
- 입력 크기 `N`과 관계없이 사용하는 메모리 크기가 일정하다.

#### 개선 가능한 부분

- 패턴을 조회할 때 `5`, `8`, `10`을 직접 사용하는 대신 `answer1.length`와 같이 배열 길이를 사용하면 패턴이 변경되어도 나머지 연산을 함께 수정할 필요가 없다.
- `maxScore` 배열은 생략할 수 있다. 첫 번째 순회에서 최고 득점자 수를 센 뒤, 두 번째 순회에서 `correctCount[i] == max`인 수포자의 번호를 결과 배열에 바로 저장하면 추가 상태가 줄어든다.
- 세 패턴을 하나의 2차원 배열로 묶으면 채점 로직의 중복을 줄일 수 있다. 다만 수포자가 세 명으로 고정된 현재 구현도 흐름이 명확하고 시간복잡도는 이미 최적인 `O(N)`이므로 성능상의 추가 개선 여지는 크지 않다.
