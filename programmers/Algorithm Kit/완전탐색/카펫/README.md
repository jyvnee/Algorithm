# 카펫

## 알고리즘 분류

- 완전탐색 (Brute Force)
- 수학 (방정식 세우기)

## 문제 정의

- 갈색(테두리) 격자 수 `brown`, 노란색(내부) 격자 수 `yellow`가 주어진다.
- 테두리 1줄이 갈색, 내부가 전부 노란색인 격자 카펫의 `[가로, 세로]`를 구한다.
- 가로 길이는 세로 길이 이상이어야 한다. (`w >= h`)
- 정답은 항상 유일하게 존재한다.

핵심 관계식은 다음과 같다. (가로 `w`, 세로 `h`)

```
내부(노란색)  : (w - 2) * (h - 2) = yellow
테두리(갈색)  : w * h - (w - 2) * (h - 2) = 2w + 2h - 4 = brown
전체 넓이     : w * h = brown + yellow
```

두 번째 식을 정리하면

```
w + h = (brown + 4) / 2 = brown / 2 + 2
```

즉 **`w + h`(둘레 관련 합)는 `brown`으로 고정**되고, `w * h`는 `brown + yellow`로 고정된다.

## 풀이 기록

### v1

#### 풀이 아이디어

- `w + h` 가 상수라는 점을 이용한 완전탐색.
- 세로 `h`를 최솟값 3부터 1씩 늘리고, 가로 `w`를 동시에 1씩 줄인다.
  - `h++`, `w--` 를 함께 하면 `w + h` 합이 항상 일정하게 유지된다.
- 각 후보 `(w, h)`에 대해 내부 격자 수 `(h - 2) * (w - 2)` 가 `yellow`와 같은지 확인한다.
- `h`가 3부터 시작하는 이유: `yellow >= 1` 이므로 내부는 최소 `1 x 1`, 따라서 세로는 최소 3.
- 반복 조건이 `h <= w` 인 이유: `h`가 `w`를 넘어가면 `가로 < 세로`가 되어 제약을 위반하고, `(w, h)`와 `(h, w)`는 대칭이므로 그 뒤는 볼 필요가 없다.

자료구조는 별도로 쓰지 않고, 결과만 `int[]`로 반환한다.

#### 알고리즘 풀이

1. 초기값 설정
   - `h = 3`
   - `w = (brown - 2 * h) / 2 + 2 = brown / 2 - 1`
   - 검산: `w + h = (brown / 2 - 1) + 3 = brown / 2 + 2` → 합 관계식과 일치.
   - `brown = 2(w + h) - 4` 이므로 `brown`은 항상 짝수 → 정수 나눗셈이 안전하다.
2. `h <= w` 인 동안 반복
   - `(h - 2) * (w - 2) == yellow` 이면 `[w, h]` 반환 (`w >= h` 이므로 `[가로, 세로]` 순서를 만족).
   - 아니면 `h++`, `w--` 로 다음 후보로 이동 (합은 그대로 유지).
3. 문제 조건상 정답은 반드시 존재하므로 마지막 `return new int[] {}` 는 도달하지 않는 방어 코드.

예시 확인 (`brown = 24`, `yellow = 24`)

```
w + h = 24 / 2 + 2 = 14,  w * h = 48
h = 3,  w = 11 → 내부 9 * 1 = 9   != 24
h = 4,  w = 10 → 내부 8 * 2 = 16  != 24
h = 5,  w = 9  → 내부 7 * 3 = 21  != 24
h = 6,  w = 8  → 내부 6 * 4 = 24  == 24 → [8, 6]
```

#### 시간복잡도

`O(brown)`

- `w + h` 합은 `S = brown / 2 + 2` 로 고정이고, 반복은 `h = 3` 에서 시작해
  `h`와 `w`가 만나는 지점 `h ≈ w ≈ S / 2 = brown / 4 + 1` 까지 진행된다.
- 반복 횟수 ≈ `brown / 4 - 2` → `O(brown)`.
- `brown <= 5000` 이므로 최악의 경우에도 약 1,250회로 매우 빠르다.

#### 공간복잡도

`O(1)`

- 반복문 변수 `h`, `w` 외에 추가 자료구조를 쓰지 않는다.
- 반환용 배열은 크기 2로 상수.

#### 개선 가능한 부분

- **근의 공식으로 O(1) 계산 가능**
  - `S = brown / 2 + 2` (= `w + h`), `P = brown + yellow` (= `w * h`)
  - `w`, `h` 는 `x^2 - S x + P = 0` 의 두 근이다.
  - `D = S * S - 4 * P`, `w = (S + sqrt(D)) / 2`, `h = (S - sqrt(D)) / 2`
  - 반복 없이 바로 답이 나오지만, `brown <= 5000` 이라 현재 풀이도 충분히 빠르므로 체감 이득은 작다.
- **약수 순회 방식**
  - `total = brown + yellow` 의 약수 `h` (`h <= sqrt(total)`) 를 순회하며
    `w = total / h`, `2 * (w + h) - 4 == brown` 인지 확인 → `O(sqrt(brown + yellow))`.
- **가독성**
  - `for` 초기화부의 `w = (brown - 2 * h) / 2 + 2` 가 한눈에 의미를 파악하기 어렵다.
    `int sum = brown / 2 + 2;` 처럼 "가로 + 세로 합"을 명시적 변수로 두면 의도가 드러난다.
