# N으로 표현

## 알고리즘 분류

- 동적 계획법(Dynamic Programming)
- 집합(Set)

## 문제 정의

숫자 `N`과 사칙연산, 괄호를 사용해 `number`를 만들 때 필요한 `N`의 최소 사용 횟수를 구한다.

같은 숫자를 이어 붙인 `N`, `NN`, `NNN` 등의 수도 하나의 표현으로 사용할 수 있다. `N`을 8번 이하로 사용해 만들 수 없다면 `-1`을 반환한다.

## 풀이 기록

### v1

#### 풀이 아이디어

`dp[i]`를 **N을 정확히 i번 사용해서 만들 수 있는 모든 정수의 집합**으로 정의한다.

`N`을 `i`번 사용한 표현은 다음 두 방법으로 만들 수 있다.

1. `N`을 `i`번 이어 붙인 수를 만든다.
   - 예: `N = 5`, `i = 3`이면 `555`
2. N을 사용한 횟수를 `j`번과 `i - j`번으로 나누고, 두 집합의 값에 사칙연산을 적용한다.
   - `dp[j]`의 값 `a`
   - `dp[i - j]`의 값 `b`
   - `a + b`, `a - b`, `a * b`, `a / b`

같은 값이 여러 수식에서 만들어질 수 있으므로 `HashSet`을 사용해 중복을 제거한다. 중복된 값을 다시 조합하지 않아도 되어 탐색량도 줄어든다.

#### 알고리즘 풀이

1. 인덱스와 N의 사용 횟수를 일치시키기 위해 `dp[0]`에 빈 집합을 추가한다.
2. N의 사용 횟수 `i`를 1부터 8까지 증가시키며 `currentSet`을 만든다.
3. `makeRepeatedNumber(N, i)`로 N을 `i`번 이어 붙인 수를 구해 `currentSet`에 추가한다.
4. `j`를 1부터 `i - 1`까지 순회하며 사용 횟수를 `j`와 `i - j`로 분할한다.
5. `dp[j]`와 `dp[i - j]`의 모든 값 쌍 `(a, b)`에 대해 다음 결과를 추가한다.
   - `a + b`
   - `a - b`
   - `a * b`
   - `a / b` (`b != 0`인 경우에만 계산)
6. `currentSet`에 `number`가 있다면 현재의 `i`가 최소 사용 횟수이므로 즉시 반환한다.
7. 현재 집합을 `dp`에 추가하고 다음 사용 횟수를 계산한다.
8. 8번까지 확인해도 `number`를 만들지 못하면 `-1`을 반환한다.

사용 횟수를 1부터 차례대로 검사하므로 목표값이 처음 발견된 시점의 `i`가 반드시 최소 사용 횟수이다.

#### 시간복잡도

`S_i`를 N을 정확히 `i`번 사용해 만들 수 있는 서로 다른 값의 개수라고 하면, 사용 횟수 `i`에서 수행하는 연산 수는 다음과 같다.

```text
O(S_1 × S_(i-1) + S_2 × S_(i-2) + ... + S_(i-1) × S_1)
```

따라서 N의 최대 사용 횟수를 `K`라고 할 때 전체 시간복잡도는 다음과 같다.

```text
O(Σ(i=1..K) Σ(j=1..i-1) S_j × S_(i-j))
```

각 집합의 최대 크기를 `S`라고 단순화하면 `O(K²S²)`로 나타낼 수 있다. 이 문제에서는 `K = 8`로 제한되지만, 집합의 크기는 이전 단계에서 생성된 결과에 따라 달라진다.

#### 공간복잡도

각 사용 횟수로 만들 수 있는 서로 다른 값을 모두 저장하므로 공간복잡도는 다음과 같다.

```text
O(S_1 + S_2 + ... + S_K)
```

각 집합의 최대 크기를 `S`라고 하면 `O(KS)`이며, 이 문제에서는 `K = 8`이다.

#### 개선 가능한 부분

- `N == number`일 때 바로 `1`을 반환하는 처리가 있어 첫 번째 DP 계산을 생략할 수 있다. 다만 일반 반복문에서도 동일한 결과를 찾을 수 있으므로, 코드를 더 일관되게 만들고 싶다면 해당 예외 처리를 제거할 수도 있다.
- 현재는 뺄셈과 나눗셈의 피연산자 순서가 중요하므로 모든 `j`를 순회한다. 절반의 분할만 확인하도록 바꾸려면 `a - b`, `b - a`, `a / b`, `b / a`를 모두 별도로 처리해야 한다. 구현 복잡도가 증가하고 최대 사용 횟수가 8로 작기 때문에 현재 방식도 충분히 명확하다.
- `makeRepeatedNumber`는 반복문 대신 `repeatedNumber = repeatedNumber * 10 + N`을 바깥 반복에서 누적해 매 단계 재사용할 수 있다. 최대 8번만 계산하므로 성능 차이는 작지만 중복 계산을 줄일 수 있다.
