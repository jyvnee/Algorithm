# 등굣길

## 알고리즘 분류

- 동적 계획법(Dynamic Programming)
- 격자 탐색

## 문제 정의

집 `(1, 1)`에서 학교 `(m, n)`까지 오른쪽과 아래쪽으로만 이동할 때, 물웅덩이를 피해 도착할 수 있는 최단 경로의 개수를 구한다.

오른쪽과 아래쪽으로만 이동하므로 임의의 칸에 도달하는 방법은 위쪽 칸과 왼쪽 칸에서 이동해 오는 두 가지뿐이다.

## 풀이 기록

### v1

#### 풀이 아이디어

`board[y][x]`를 `(x, y)` 위치까지 도달하는 경로의 개수로 정의한다.

각 칸은 다음 점화식으로 계산한다.

```text
board[y][x] = board[y - 1][x] + board[y][x - 1]
```

- `board[y - 1][x]`: 위쪽 칸에서 이동해 오는 경로
- `board[y][x - 1]`: 왼쪽 칸에서 이동해 오는 경로

물웅덩이는 미리 `-1`로 표시한다. 격자를 순회하다가 물웅덩이를 만나면 값을 `0`으로 바꾸고 다음 칸으로 넘어간다. 이후의 칸은 해당 위치를 통해 올 수 있는 경로가 없다고 판단하게 된다.

#### 알고리즘 풀이

1. `n + 1` 행과 `m + 1` 열을 갖는 `board`를 생성한다.
2. 물웅덩이 좌표 `(x, y)`를 `board[y][x] = -1`로 표시한다.
3. 출발지인 `board[1][1]`을 `1`로 초기화한다.
4. 위쪽에서 아래쪽으로, 왼쪽에서 오른쪽으로 격자의 모든 칸을 순회한다.
5. 물웅덩이는 `0`으로 변경하고 계산하지 않는다.
6. 출발지를 제외한 각 칸에 위쪽과 왼쪽 칸의 경로 수를 더해 저장한다.
7. 모든 경로 수는 `1,000,000,007`로 나눈 나머지로 관리한다.
8. 학교의 위치에 저장된 `board[n][m]`을 반환한다.

배열의 `0`번째 행과 `0`번째 열은 기본값인 `0`으로 남겨 둔다. 따라서 첫 번째 행과 첫 번째 열도 별도의 범위 검사 없이 같은 점화식으로 계산할 수 있다.

#### 시간복잡도

```text
물웅덩이 표시: O(P)
격자 순회: O(MN)

O(P) + O(MN)
→ O(MN)
```

`P`는 물웅덩이의 개수이다. 각 격자 칸을 한 번씩만 방문하므로 시간복잡도는 `O(MN)`이다.

#### 공간복잡도

```text
O(MN)
```

각 위치까지의 경로 수와 물웅덩이 여부를 저장하기 위해 `n × m` 크기의 2차원 배열을 사용한다.

#### 개선 가능한 부분

현재 칸의 경로 수를 계산할 때는 직전 행과 현재 행의 값만 필요하다. 따라서 1차원 배열로 바꾸면 공간복잡도를 `O(MN)`에서 `O(M)`로 줄일 수 있다.

#### 시행착오

- 초기 구현에서는 학교로부터의 거리가 같은 칸들을 대각선 단위로 탐색했다.
- 대각선의 길이를 기준으로 반복하면서 격자 범위 밖의 좌표도 생성한 후 검사했기 때문에 불필요한 반복이 발생했다.
- 이 방식의 시간복잡도는 `O((M + N)²)`이며, 효율성 테스트에서 시간 초과가 발생했다.
- 해결을 위해 대각선 단위 탐색을 제거하고, 실제 격자 범위의 각 칸만 한 번씩 방문하도록 행과 열을 직접 순회했다.
- 그 결과 시간복잡도를 `O((M + N)²)`에서 `O(MN)`으로 개선했고, 불필요한 좌표 계산과 범위 검사도 제거했다.
