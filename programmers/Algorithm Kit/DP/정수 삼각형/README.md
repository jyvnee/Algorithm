# 정수 삼각형

## 알고리즘 분류

- 동적 계획법(Dynamic Programming)

## 문제 정의

삼각형의 꼭대기에서 시작해 아래쪽의 인접한 칸으로 이동하며, 바닥까지 도달했을 때 거쳐 간 숫자 합의 최댓값을 구한다.

각 위치에서는 바로 아래 행의 왼쪽 칸 또는 오른쪽 칸으로만 이동할 수 있다.

## 풀이 기록

### v1

#### 풀이 아이디어

`dp[i][j]`를 삼각형의 꼭대기에서 `i`번째 행의 `j`번째 원소까지 이동했을 때 얻을 수 있는 최대 합으로 정의한다.

삼각형 내부의 한 위치에는 이전 행의 다음 두 위치에서 올 수 있다.

- 왼쪽 위: `dp[i - 1][j - 1]`
- 오른쪽 위: `dp[i - 1][j]`

따라서 두 경로 중 합이 더 큰 경로를 선택한 뒤 현재 값을 더한다.

```text
dp[i][j] = max(dp[i - 1][j - 1], dp[i - 1][j]) + triangle[i][j]
```

각 행의 양쪽 끝은 도달할 수 있는 이전 위치가 하나뿐이므로 별도로 계산한다.

```text
dp[i][0] = dp[i - 1][0] + triangle[i][0]
dp[i][i] = dp[i - 1][i - 1] + triangle[i][i]
```

마지막 행의 각 값은 꼭대기에서 해당 위치까지의 최대 합이므로, 그중 가장 큰 값이 전체 경로의 최대 합이다.

#### 알고리즘 풀이

1. 삼각형의 높이와 같은 행과 열을 갖는 `dp` 배열을 생성한다.
2. 꼭대기의 값 `triangle[0][0]`을 `dp[0][0]`에 저장한다.
3. 두 번째 행부터 마지막 행까지 순회한다.
4. 현재 행의 왼쪽 끝은 바로 위의 왼쪽 끝에서 내려오는 경로로 계산한다.
5. 행 내부의 각 위치는 왼쪽 위와 오른쪽 위의 누적 합 중 큰 값에 현재 숫자를 더해 계산한다.
6. 현재 행의 오른쪽 끝은 이전 행의 오른쪽 끝에서 내려오는 경로로 계산한다.
7. 마지막 행을 순회해 가장 큰 누적 합을 반환한다.

#### 시간복잡도

```text
DP 배열 계산: 1 + 2 + ... + N = O(N²)
마지막 행 탐색: O(N)

O(N²) + O(N)
→ O(N²)
```

높이가 `N`인 삼각형에는 총 `N(N + 1) / 2`개의 원소가 있으며, 각 원소를 한 번씩 계산하므로 시간복잡도는 `O(N²)`이다.

#### 공간복잡도

```text
O(N²)
```

각 위치까지의 최대 누적 합을 저장하기 위해 `N × N` 크기의 2차원 배열을 사용한다.

#### 개선 가능한 부분

- 현재 행의 값을 계산할 때는 이전 행의 값만 필요하므로 1차원 DP 배열을 사용하면 공간복잡도를 `O(N²)`에서 `O(N)`으로 줄일 수 있다.
- 1차원 배열을 제자리 갱신할 때는 아직 사용하지 않은 이전 행의 값이 덮어써지지 않도록 오른쪽에서 왼쪽으로 순회해야 한다.
- 입력 배열을 수정해도 된다면 `triangle` 자체에 누적 합을 저장하여 별도의 DP 배열 없이 풀이할 수도 있다. 다만 입력 데이터가 변경된다는 부작용이 있으므로 사용 조건을 명확히 해야 한다.
