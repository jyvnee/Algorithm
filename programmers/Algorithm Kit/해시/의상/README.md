# 의상

## 풀이 기록

### v1

#### 문제 정의

의상을 종류별로 최대 한 개씩 선택할 때 만들 수 있는 서로 다른 착용 조합의 수를 구한다.
하루에 최소 한 개의 의상은 착용해야 하므로, 모든 종류에서 의상을 선택하지 않는 경우는 제외해야 한다.

#### 풀이 아이디어

`HashMap<String, Integer>`을 사용해 각 의상 종류에 속한 의상의 개수를 센다.

어떤 종류의 의상이 `n`개라면 해당 종류에서는 다음 `n + 1`가지 선택이 가능하다.

- `n`개의 의상 중 하나를 착용한다.
- 해당 종류의 의상을 착용하지 않는다.

각 종류의 선택은 서로 독립적이므로 종류별 선택 가능 횟수를 모두 곱한다. 이 결과에는 모든 종류의 의상을 착용하지 않는 경우도 포함되므로 마지막에 `1`을 뺀다.

#### 알고리즘 풀이

1. 모든 의상을 순회하며 의상 종류를 키로, 해당 종류의 의상 개수를 값으로 저장한다.
2. 정답을 `1`로 초기화한다.
3. 해시맵에 저장된 종류별 의상 개수 `value`를 순회한다.
4. 각 종류마다 의상을 착용하지 않는 선택을 포함해 `value + 1`을 정답에 곱한다.
5. 아무 의상도 착용하지 않은 한 가지 경우를 제외하기 위해 최종 결과에서 `1`을 뺀다.

예를 들어 머리 의상이 2개이고 얼굴 의상이 1개라면 선택 가능한 경우의 수는 다음과 같다.

```text
(머리 의상 2개 + 미착용 1가지) × (얼굴 의상 1개 + 미착용 1가지) - 전체 미착용 1가지
= 3 × 2 - 1
= 5
```

#### 시간복잡도

시간복잡도: **O(N)**

전체 의상 `N`개를 한 번 순회하여 종류별 개수를 집계하고, 서로 다른 의상 종류 `K`개를 한 번 순회한다.

```text
O(N) + O(K)
→ O(N)  (K ≤ N)
```

#### 공간복잡도

공간복잡도: **O(K)**

서로 다른 의상 종류의 수를 `K`라고 할 때, 해시맵에 종류별 개수를 저장한다. 최악의 경우 모든 의상의 종류가 다르므로 `K = N`이며, 이때는 `O(N)`의 공간을 사용한다.
