# 2001. 파리 퇴치

## 알고리즘 분류

브루트포스 / 2차원 배열 부분합

## 문제 정의

N×N 배열에 파리 수가 주어질 때, M×M 크기의 파리채로 한 번 내리쳐 잡을 수 있는 파리 수의 최댓값을 구한다.

## 풀이 기록

### v1

#### 풀이 아이디어

파리채를 놓을 수 있는 좌상단 좌표 `(i, j)`를 `0 ≤ i, j ≤ N-M`까지 모두 완전탐색하면서, 그때마다 M×M 영역의 합을 직접 계산해 최댓값을 갱신하는 브루트포스 방식이다. N이 최대 15로 작기 때문에 4중 반복문으로도 충분히 시간 내에 해결 가능하다.

#### 알고리즘 풀이

1. N, M을 입력받고 N×N 배열 `board`를 채운다.
2. 파리채의 좌상단이 위치할 수 있는 범위는 `0 ~ N-M`이므로 `num = N - M + 1`로 계산한다.
3. `i, j`를 `0..num-1`까지 이중 반복하며 각 위치에서 파리채가 덮는 M×M 영역을 `r, c` 이중 반복문으로 순회해 `count`에 합산한다.
4. `count`가 `answer`보다 크면 갱신하고, 모든 위치를 탐색한 뒤 `answer`를 출력한다.

#### 시간복잡도

O(N² × M²) (테스트 케이스당)

파리채 위치 후보가 최대 N²개이고, 각 위치마다 M×M 영역의 합을 구하는 데 M²이 걸리므로 O(N² × M²)이다. N, M ≤ 15로 제한이 작아 브루트포스로도 충분하다.

#### 공간복잡도

O(N²)

N×N 크기의 `board` 배열만 사용한다.

#### 개선 가능한 부분

- 2차원 누적합(prefix sum)을 미리 구해두면 임의의 M×M 영역 합을 O(1)에 계산할 수 있어, 전체 시간복잡도를 O(N²)로 줄일 수 있다. 다만 N, M의 제약이 작아 현재 브루트포스로도 성능상 문제는 없다.
